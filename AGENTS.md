# Projektregler

## Bygg minimalt

- Generera inte stora mängder kod åt gången.
- Bygg projektet stegvis och implementera endast den minsta kod som behövs för nästa verifierbara steg.
- Förklara kort vad varje kodändring ska uppnå innan den görs.
- Verifiera varje steg innan vi går vidare.
- Lägg inte till funktioner, abstraktioner eller beroenden innan de behövs.
