# RiggsVsReese.Api

## Framtida syfte

Den här mappen är reserverad för en framtida webbserver. En webbklient skulle då kunna skicka HTTP-anrop i stället för att använda terminalen.

## Ska känna till och ta hjälp av

API-projektet skulle känna till HTTP och anropa samma services och Core-regler som terminalappen. Det skulle ta hjälp av Infrastructure för tekniska implementationer.

## Ska inte göra

API:t får inte innehålla egna spelregler. Mappen är inte ett byggbart projekt ännu eftersom spelet bara använder terminalen.
